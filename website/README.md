# Сайт TERRASA — уличные кухни из нержавеющей стали

Готовый **многостраничный** сайт с онлайн-калькулятором и приёмом заявок.
Чистый HTML/CSS/JS — без сборки и зависимостей. Работает на любом хостинге,
можно открыть даже двойным кликом по `index.html`.

```
website/
├── index.html        ← Главная (герой, преимущества, тизер каталога)
├── catalog.html      ← Каталог модулей (фильтр TERRASA / VERANDA)
├── calculator.html   ← Калькулятор стоимости (сборка комплекта)
├── about.html        ← О производстве, этапы работы, галерея, FAQ
├── contacts.html     ← Контакты + форма заявки
├── css/styles.css    ← оформление (тёмная + светлая тема)
└── js/
    ├── config.js     ← ⭐ ВСЕ НАСТРОЙКИ ЗДЕСЬ (контакты, цены)
    └── app.js        ← общая логика: шапка/подвал, каталог,
                         калькулятор, корзина и форма
```

**Шапка и подвал одинаковы на всех страницах** и генерируются из `app.js` —
менять меню/контакты нужно в одном месте (`config.js`), а не в каждом файле.

**Корзина калькулятора переносится между страницами:** модуль, добавленный
кнопкой «В расчёт +» в каталоге, окажется в калькуляторе, а из калькулятора
комплект автоматически подставляется в форму заявки на странице «Контакты».

## 1. Что обязательно поменять перед публикацией

Откройте **`js/config.js`** и впишите свои данные:

| Поле | Что это |
|------|---------|
| `phoneRaw` / `phonePretty` | ваш телефон (для ссылок и для показа) |
| `whatsapp` | номер WhatsApp — **сюда приходят заявки с формы** |
| `telegram` | ваш логин в Telegram без `@` |
| `email` | почта для документов и чертежей |
| `legalName`, `city`, `address` | реквизиты для футера |
| `modules[].price` | ваши реальные цены модулей (сейчас стоят ориентировочные) |

Больше нигде ничего править не нужно — весь сайт берёт данные из этого файла.

## 2. Куда приходят заявки

В `config.js` есть поле `leadDelivery`:

- **`"whatsapp"`** (по умолчанию) — при отправке формы открывается WhatsApp
  с уже заполненной заявкой (имя, телефон, комплект). Работает сразу, ничего
  настраивать не нужно. Заявки приходят вам в мессенджер.
- **`"email"`** — открывается почтовая программа с заполненным письмом.
- **`"endpoint"`** — заявка отправляется на ваш backend. Самый «серверный»
  вариант: заведите бесплатную форму на [formspree.io](https://formspree.io)
  (или свой скрипт), вставьте URL в `formEndpoint` — заявки будут падать
  вам на почту автоматически, без действий клиента.

> Каждая заявка дополнительно сохраняется в браузере (localStorage), чтобы
> ничего не терялось при тестировании.

## 3. Как посмотреть локально

```powershell
cd website
python -m http.server 8777
```
Откройте <http://127.0.0.1:8777> в браузере.

## 4. Как опубликовать в интернете (бесплатно)

Это статический сайт, поэтому подойдёт любой из вариантов:

- **Netlify** или **Vercel** — перетащите папку `website/` на netlify.com/drop.
- **GitHub Pages** — залейте папку в репозиторий, включите Pages.
- **Обычный хостинг** — загрузите содержимое `website/` в корень сайта по FTP.

Домен (например `terrasa-kitchen.ru`) подключается в настройках хостинга.

## 5. Что улучшить со временем

- **Фотографии.** Сейчас в каталоге и галерее — векторные схемы модулей.
  Замените их на реальные фото готовых кухонь: доверие и заявки заметно
  вырастут. (Фото кладите в `assets/`, вставляйте в карточки вместо `<svg>`.)
- **Реальные отзывы** вместо примера в блоке-цитате.
- **Аналитика** (Яндекс.Метрика / Google Analytics) — вставьте счётчик в
  `<head>` файла `index.html`, чтобы видеть посетителей и заявки.
- **Политика обработки перс. данных** — отдельная страница, ссылку добавить
  под формой (требование 152-ФЗ при сборе телефонов).
